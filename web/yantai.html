两条独立发现通道

通道 A · 全域低成本持续发现

Sentinel-2 / Landsat / HLS / Sentinel-1，固定周期广覆盖筛查，先解决“有没有新变化”。

通道 B · 重点区域高分辨率直接巡查

GF-2 / GF-7 等 0.8 m 级影像，对重点区和通道 A 线索定向复核，解决“是什么、规模多大”。

两通道互补，不能互相替代；高分采购合同应约定最小采购面积、实际覆盖、云与薄云标准、侧视角、定位精度、失败补拍、原始多光谱交付、分析授权和交付时限。

分类型计算方式：六类行为分开建模

不同非法采矿行为的观测对象、主指标、最小可识别尺度都不同，不能把 BSI+CUSUM 这一套阈值直接套到全部类别。当前只有 BC1 有可运行方法。

共同边界：六类都不认定违法；面积是变化像元聚类面积，不是测绘面积；缺测与“未建模”都不能写成“无异常”。分类建模属于 G2（识别有效）前置工作。

八层筛选：每层都要能回答“排除了什么”

  • 0 数据准入：SCL/云掩膜、反射率偏移、跨期配准；不合格的像元先标未知。
  • 1 广覆盖变化：BSI / NDVI / NBR 时序变化，先找出所有可疑裸化。
  • 2 季节与自然背景：稳健季节谐波 + CUSUM（BFAST Monitor 对照），剔除物候与水文节律。
  • 3 对象类型：逻辑回归基线 → RF / GBDT，区分裸地、堆场、建筑、农田与采掘。
  • 4 时序持续性：要求持续超阈，不把单景噪声当事件。
  • 5 跨源与高分核查：Sentinel-1 辅助 + GF-2 / GF-7 目视与对象边界。
  • 6 时空许可核验：矿权、河道管理范围、禁采期；没有图层就写“待核”。
  • 7 人工与现场闭环：核查队列、现场反馈、漏报抽查。

每层分别记录“保留 / 分流 / 排除 / 未知”及原因码。若每层各保留 95% 真目标，连续 5 层只剩约 77.4%——必须直接评价完整链条的召回率，不能假设层间独立。

评价口径

  • 事件级 Precision / Recall / F1；未知与缺测不计入 TN，TP/FP/FN 必须相对明确类别与时段。
  • 空间块或矿点留出、未来时段测试；历史回放只用当时可得数据；对照试验保留简单双时相基线。
  • 样本量示例：Precision≈0.80、95% 区间半宽≈0.05 约需 246 个已判明预测正事件（规划量级）。
  • 当前没有 2025 独立高分参考，F2 未达成，不计算 precision/recall；“level:F1”是项目阶段层级，不是 F1 分数。

数据优先级

P0 · 可信分析的基础正式监测边界与基础地理；许可与管理约束；同期独立参考资料；可持续多源影像。
P1 · 提升识别与复核高分历史与新增影像；气象、水文、潮汐；DEM；本地标注与现场闭环库。
P2 · 重点区补充重点区地面观测。

P0 不是“以后再补”的附属项，而是可信分析与业务判断的前提。

建设门槛 G1—G4

G1 结果可信v2 端到端修订 + 全年重跑 + 时空范围核对 + 质量复核 + 隔离旧结果
G2 识别有效独立标签 + 难负例 + 空间/时间留出 + 分层评价 + 确定主模型
G3 持续可用新影像 + 增量处理 + 事件去重 + 质量告警 + 核查队列 + 影子运行
G4 业务闭环历史许可与约束边界 + 人工现场反馈 + 服务时限 + 持续抽查漏报

顺序：先修正并验证现有分析 → 再补独立真值与正式许可 → 同时建设持续数据入口。

时延与资源量级

  • 总时延 = 等待有效观测 + 数据交付 + 自动处理 + 人工复核/派发；Sentinel-2 重访 5 天，HLS 约 2—3 天 / 30 m。
  • 建设目标（不是当前能力）：数据到达后 2 小时内完成筛查，高优先级线索 24 小时内完成初核。
  • 复核人时 = 日候选数 × 单对象平均初核分钟 / 60 + 复杂复核协调；每天 100 个候选、每个 8 分钟，仅初核约 13.3 人时。
  • 试点起点：16—32 核 / 64—128 GB 内存 / NVMe；训练分割模型再评估 16—24 GB 显存。
  • 10 m 网格、10 个 Float32 波段、100 时相，每平方公里原始数组约 40 MB（量级示例，不含 SAR SLC、高分与附加存储）。

不能把减少人工的压力转化为静默删除低分线索；低分线索应分流而不是消失。
