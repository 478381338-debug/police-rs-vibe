**口径约定**

- 语速按 4.5–5 字/秒设计，约 1500 字旁白；可在不影响数字的前提下微调停顿。

## 录制执行清单

### 1. 起服务与自检

```bash
cd E:\警务遥感\vibe_repo
E:\警务遥感\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8091
```

录制前逐个访问并确认 200：`/`、`/yantai`、`/sixg`、`/workspace`、`/m`、`/aircase`。如果烟台页空白，先查 8080 是否还挂着旧进程，不要先清缓存——这是链路三的真实教训。

### 2. 浏览器与画面

- Chrome / Edge，1920×1080，缩放 100%，F11 全屏，隐藏书签栏。
- 用干净的用户配置，关闭通知、下载弹窗和输入法候选框。
- 6G 页有 3D 动画，点击场景后停 1–2 秒再开始旁白，避免录到首帧闪烁。
- 手机镜头单独用 390×844 设备模拟录制，或把 `mobile.png` 放进等比例手机框；不要把它塞进 1920 画布后整体放大。
- 画面里的 24.0 和 22.4 是两个口径；字幕按脚本写，不要合并成一个数。

### 3. 声音与字幕

- 旁白 −16 LUFS 左右，BGM 压到 −28 dB 以下，无歌词。
- 数字读法：342 读“三百四十二”，343 读“三百四十三”；“0.54 公顷”不要读成“零点五十四”。
- 字幕与画面数字逐字核对；尤其 307 ms、75%、885.4、24.0、22.4、0.54。
