# 烟台市遥感预警系统现状与建设需求报告

**核对日期：2026年11月15日，北京时间。**

本报告依据当前项目代码、结果文件及已核实的公开技术资料编写。截图用于衔接此前进度；已有方案中的设想不计作已完成能力。现状判断来自本地文件和源代码核对，本次未重新运行全年影像分析，也未完成在线系统验收。下文将“自然资源预警”界定为矿产、河道砂石、林地、耕地、湿地与岸线等资源的异常扰动和疑似违规利用预警，不扩展为所有自然灾害预报。

**总体判断：项目已达到“小范围历史遥感分析、有结果的算法原型、可展示和记录研判的业务平台”阶段；尚未达到“烟台全市持续运行、准确性经过独立验证、能够自动产生并闭环处置新增预警”的阶段。** 当前最缺的不是再增加一个模型名称，而是可靠的时序数据处理、带日期的独立参考样本、正式许可边界，以及持续获取数据和核查反馈的机制。

## 一、目前已做到什么程度

- `mining_belt`：经纬度范围 `[120.15, 37.08, 120.36, 37.21]`。
- `A_control`：经纬度范围 `[120.06, 37.40, 120.13, 37.47]`。

原版主要采用20米分析网格。设置的0.5公顷最小面积不是“可稳定识别0.5公顷采矿”的性能证明；原结果仍有0.48公顷对象。v2向上取整后，20米网格至少13个像元，对应0.52公顷。目标的最窄宽度、形状、背景和混合像元仍影响可检出性。

### 2. 已形成可继续使用的分析基础

现有流程已覆盖影像目录、下载缓存、光学指数、历史季节背景、累积变化检测、连通对象和候选结果输出。v2采用2022—2023年数据建立2024年标定模型，再把2024年纳入最终历史基线。这为后续因果时序监测提供了基础，但基线代表性、观测密度和阈值仍需验证。[本地5]

SAR实验说明项目已具备雷达数据处理的探索基础。两组InSAR日期分别为2023-01-03至01-15、01-15至01-27；每组统计4899个有效样区像元，平均相干性约0.9448和0.9333。高相干性仅说明这些干涉对具备一定相位可用性，不证明形变真实、不证明由采矿引起，也不支持外推长期沉降速率。[本地4]

InSAR位移通常是相对参考点的雷达视线向分量，还需检查解缠、轨道、大气和参考点稳定性。单轨视线向结果只有在明确运动方向假设后才能近似换算为垂向位移；已有文件名含`vert_disp`并不意味着已完成独立垂向测量验证。

旧材料中将LiCSAR的`*.sltd.geo.tif`解释为地表位移的说法不能继续引用。该数据属于斜距方向对流层延迟；LiCSBAS处理文档明确把它用于大气校正，相关延迟量以弧度表示。不能把其数值换个单位当作沉降成果。[外部7]

### 3. 已有业务原型，但不是实时卫星系统

当前接口版本为`0.2.0-pilot`，明确标注“本地试点数据检查（非实时卫星推送）”。现有事件、影像对比和研判入口可以继续复用；研判写入已有角色限制和历史记录，不能再把这些功能笼统列为完全未做。[本地6]

目前的关键边界是：

- `/check`记录检查时间、次数和本地文件指纹；没有查询卫星新影像并启动分析的生产链，返回的`new_events`固定为0。
- 页面中的河道资料不足记录，不是已经发现的非法采砂事件。
- `/permits`仍返回空许可列表；资源点和河流中心线不能代替法定权属与管理范围。
- 评估接口指向`data/yantai_2025_v2`，不是已完成的小试目录`data/yantai_2025_v2_test`。

因此，“平台可打开”“能点检查”“有候选图斑”和“能持续预警”是四件不同的事。

## 二、尚未完成什么

### 1. 直接影响现有结果可信度的缺口

| 未完成事项 | 当前依据与影响 | 完成判据 |
|---|---|---|
| 完整v2全年重跑及复核 | 核对时`data/yantai_2025_v2/summary.json`不存在，两个正式v2报告文件也不存在 | 冻结代码与参数；完整生成两样区全年结果；逐项比较新旧对象、时间、面积与质量字段 |
| 反射率逐产品核验 | 代码当前使用全局`BOA_ADD_OFFSET=-1000`；尚不能据此证明对不同处理基线、提供方和已协调产品均正确 | 从实际产品元数据确定比例和偏移；证明只转换一次；保留元数据与版本 |
| 波段和跨期严格配准 | 当前存在各原生波段窗口分别取整后缩放的实现路径 | 核对统一CRS、像元大小、原点和范围；用稳定地物测量跨期配准误差 |
| 阈值端到端校准 | 阈值仍有上下限；历史和目标观测密度不同；`h_sensitivity`复用原阈值下的报警次数 | 每组阈值重新执行完整报警、对象提取和评价；按相近观测条件标定误报负担 |
| 时间和覆盖率语义 | 月度目录日期不代表对象晴空可见；`t0`仅为首次报警前有任意对象像元有效的日期 | 输出对象清晰比例、有效日期和缺测间隔；有充分证据才给出变化发生区间 |
| 独立精度评价 | 没有覆盖目标年份、目标事件和非候选区的独立参考标签 | 空间及时间留出测试；报告事件级Precision、Recall、F1及不确定性 |

“99.5%历史分位阈值”不等于“0.5%业务误报率”。背景自相关、累计监测、多次检验、观测次数和对象合并都会改变实际误报负担。已有汇总文件中的`level: F1`也是项目层级标识，不能作为F1分数引用。

v2小试的双时相对照使用2024-11-01和2025-02-24，不是严格同季节对照。候选减少可能来自时间变短、影像减少、处理变化或阈值变化，不能直接归因为模型更准确。

### 2. 从试验走向可用预警的缺口

1. **全域范围未建立。** 未见烟台正式行政边界内统一网格、分区覆盖统计和持续监测结果；两个样区不能代表城市、山区、海岸和河道的全部背景。
2. **任务尚未分开建模。** 露天采矿、地下采矿地表迹象、河道采砂和其他资源扰动具有不同观测条件，不能共用一套裸地阈值完成识别。
3. **没有足够的本地正负样本。** 缺少带日期的真实活动样本，以及建设施工、农田翻耕、果园管理、自然滑塌、河滩出露等难负例。
4. **许可核验未接通。** 不能可靠区分无证、越界、过期、禁采期活动与合法施工；空间相交本身也不能证明合法。
5. **持续数据链未接通。** 缺新影像发现、增量下载、处理调度、失败补偿、质量拦截、事件更新、消息推送和服务监控。
6. **闭环核查未验证。** 已有研判记录能力，但没有经过实际运行证明的任务派发、现场反馈、纠错标注和模型更新闭环。

不宜给出“完成70%”一类比例。当前没有经共同确认、可加权的验收清单；应按上述能力逐项验收。

## 三、实现及时预警需要什么模型和分析方法

### 1. 先明确“实时”的可实现边界

预警时延应拆成：

`总时延 = 等待有效观测 + 数据交付 + 自动处理 + 人工复核/派发`

Sentinel-2常规星座设计重访为5天；重叠轨道和附加观测可能缩短间隔，但不能当作烟台每个点的保证。NASA HLS提供约2—3天全球观测频率的协调产品，空间网格为30米；云、阴影和交付延迟仍存在，且30米不能代替小目标高分辨率影像。[外部1、2]

**合理产品定位：全域卫星近实时筛查，加重点区域高频定向观测。** 对具备合格新影像的事件，可以追求小时级处理；对事发后的发现时间，通常受卫星有效观测间隔限制。要求分钟级发现的固定重点点位，需要依法部署的视频、地面传感器或经批准的无人机巡查，不能仅靠免费光学卫星承诺实现。

建议在试运行压测后再确定服务指标。初始可讨论“数据到达后2小时内完成筛查、高优先级线索24小时内完成初核”，但这只是建设目标，不是当前能力，也不包含卫星尚未观测到的时间。

### 2. 采用两条独立发现通道

**通道A：全域低成本持续发现。** 使用Sentinel-2、Landsat/HLS及必要的Sentinel-1，对全市统一网格更新变化状态。优先保持广覆盖和召回能力，输出候选对象及其质量、日期和不确定性。

**通道B：重点区域高分辨率直接巡查。** 对历史风险区、矿权边界带、关停矿山、重点河段、生态敏感区安排独立的高分影像或无人机核查。它既可响应通道A，也必须有自主巡查计划；否则小坑口、窄道路、小面积采挖一旦被粗分辨率漏掉，就永远进不了精查环节。

重点区不是永久封闭名单。定期抽查低风险区和无候选区，防止只在已知矿点附近发现问题。距离已知矿点只能影响排序，不能成为“允许产生候选”的条件。

### 3. 推荐的模型组合及采用顺序

| 层次 | 优先模型或方法 | 输入与产出 | 采用理由与约束 |
|---|---|---|---|
| 数据质量层 | SCL/云概率、必要时Cloud Score+；几何配准；质量权重 | 原始反射率、质量掩膜、元数据；输出有效观测 | 先防止云、偏移和错位被识别为变化；云阈值须本地校准 |
| 时序发现层 | 稳健季节谐波回归，加单侧CUSUM；BFAST Monitor作对照 | 多年多波段与指数时序；输出偏离历史背景的时间、方向、持续性 | 可解释、与当前代码衔接好；BFAST Monitor面向新到观测扰动监测[外部4] |
| 历史背景层 | CCDC；必要时LandTrendr年度分段 | 长时间序列；输出稳定期、断点和长期恢复/退化趋势 | 用于区分长期裸地、历史扰动和新增变化；年度方法不替代及时预警[外部5] |
| 对象分类层 | 逻辑回归作基线，Random Forest或梯度提升树作主候选 | 光谱、时序、纹理、几何、地形和邻域特征；输出活动类型及经校准的置信度 | 适合先从有限本地标签起步；可分析误报来自哪些特征 |
| 高分辨率识别层 | U-Net/SegFormer语义分割；Siamese、BIT或ChangeFormer双时相变化检测 | 严格配准的高分辨率前后影像；输出采坑、堆场、道路及变化边界 | 在本地独立测试优于基线后再采用；不凭论文排名选生产模型[外部6] |
| 雷达辅助层 | 同轨多时相后向散射、极化比、纹理和结构变化；条件允许时用相干性 | GRD/RTC或SLC；输出支持、冲突或无法判断的观测 | 可补充多云期；湿度、耕作、地形阴影和观测几何也会引起变化 |
| 形变专项层 | SBAS/PS-InSAR，MintPy等工具 | 较长同轨SLC序列、轨道、DEM、大气校正和参考点 | 只作为地表形变风险分支；不把形变当作采矿或违法的直接证据[外部7] |
| 业务判别层 | 带有效期的空间规则、许可规则及人工核查 | 活动对象、许可与约束边界、时段、现场材料 | 将“确有扰动”“像采矿”“许可冲突”分开，不训练黑箱直接输出违法结论 |

SAM类模型可辅助描绘标注边界，不能自动生成可靠的采矿真值。遥感基础模型或自监督预训练可用于少样本迁移，但只能作为对照方案；本地测试、误报负担和部署成本决定是否采用。语言模型适合整理已有材料和生成待审核摘要，不负责凭图像认定违法。

### 4. 时序和对象分析的关键设计

对像元或对象建立季节背景，可采用：

`x(t) = a + b*t + Σ[c_k*sin(2πkt) + d_k*cos(2πkt)] + ε(t)`

对质量合格观测计算稳健标准化残差：

`z(t) = [x(t) - x_hat(t) - median(ε_baseline)] / max(1.4826*MAD(ε_baseline), s_min)`

再按目标变化方向构造累积量：

`G(t) = max(0, G(t-1) + z_direction(t) - k)`

这里的公式是推荐设计，不表示现有代码已实现全部细节。季节公式的`t`以年为单位，`k`是谐波序号；CUSUM公式的`k`另指允许漂移参数。漂移参数、报警阈值、季节项数和尺度下限均应通过本地历史回放选定。对长期缺测应暂停或按明确规则重置状态，不能用插值观测积累“真实报警证据”。

具体应做到：

- **多指标而非单一裸地指数。** 联合原始波段、BSI、NDVI、NBR、NDMI和水体特征。已有裸地内部继续采挖可能没有明显NDVI下降，需补充边界扩张、纹理、堆料和道路变化。
- **按地类与季节建立背景。** 果园、耕地、建设区、山地、河滩和海岸分别评估。可利用同区域稳定参照对象消除共同天气影响，但须确认参照本身未变化。
- **兼顾突变与渐变。** 快速开挖用突变检测；持续扩张用面积增量、边界位移和稳健趋势。不能只检测首次变裸，随后停止跟踪。
- **对象聚合与事件去重。** 用空间重叠、邻近和时间连续性关联图斑，保留拆分、合并关系。同一处持续活动应更新事件，不应每景生成一个“新案件”。
- **校准概率与拒判。** 用独立验证集校准活动类别概率；对未知地类、传感器变化和置信度不足保留“无法判断”。规则分数或CUSUM值不是违法概率。
- **防止更新污染。** 事件未核清前，不把变化后的观测自动纳入正常基线；确认合法或恢复稳定后，按版本更新背景。

### 5. 不同资源对象需要不同分支

| 对象 | 推荐观测与方法 | 必须防范的误解 |
|---|---|---|
| 露天开采、采石和取土 | 植被转裸地、原有裸地扩张、采坑/台阶/堆场、运输道路的时序与对象模型；高分影像核查 | 施工场地也会有道路和堆场；仅裸地增加不足以判采矿 |
| 地下矿山及隐蔽小坑口 | 高分辨率检查新增入口、废石堆、道路与设施；有条件再加形变和授权地面观测 | 卫星不能看穿地表；无沉降不等于无开采，有沉降也不等于违法开采 |
| 河道采砂 | 动态水陆边界、同水位比较、砂堆与便道、船舶/设备迹象；结合水位、流量、降雨及河道许可 | 退水露滩、洪水冲淤和浑水都可能造成类似变化；浑浊度不是采砂专属信号 |
| 林地、耕地扰动 | 地类转换、物候偏离、持续裸露、硬化及施工对象；结合林地/耕地边界和审批 | 果园修剪、正常收获、轮作、季节休耕不能直接判破坏资源；历史地类也不能作为排除变化的理由 |
| 湿地、海岸与围填扰动 | 同潮位岸线、水体转陆地、持续堆填及堤埂形态；结合潮位与用海资料 | 潮汐、风浪、养殖管理和季节水位变化不能直接判围填或侵占 |

对采挖体积，仅在有可比较的高精度DEM/DSM和误差预算时估算。`体积≈Σ(高程差×单元面积)`仍受配准、植被、堆料、基准和测量误差影响；二维扰动面积不能换算成可靠开采量。

## 四、怎样层层验证、缩小范围并排除异常值

### 1. 先区分四类“异常”

1. **观测伪异常：** 云、云影、积雪、错位、比例偏移、拼接缝、SAR阴影等。应通过质量处理剔除或降权。
2. **真实但非目标变化：** 耕作、施工、洪水冲淤、修复工程等。应标注原因并分流，不当作坏数据删除。
3. **真实目标异常：** 采挖、扩张等稀有事件。它们恰是系统要保留的信号，不能被通用“去极值”算法抹掉。
4. **未知与缺测：** 被云遮挡、分辨率不足、资料缺失或新类型。应保持待判，不计为无异常或真负例。

因此，不建议用统一的三倍标准差、箱线图或Isolation Forest直接删除所有离群像元。异常检测模型可用于质量提示和未知样本发现；是否删除必须依据观测质量和具体任务。

### 2. 建立可回查的八层筛选流程

| 层级 | 具体检验 | 缩小范围的方式 | 保留与复核要求 |
|---|---|---|---|
| 0. 数据准入 | 产品时间、处理基线、反射率、云影、NoData、投影、配准、SAR轨道及地形遮蔽 | 排除不可用观测，不排除真实区域 | 标记缺测与失败原因；不把处理失败显示为“正常” |
| 1. 广覆盖变化 | 季节残差、CUSUM、断点、边界增量；重点区同时直接高分检测 | 形成高召回候选，而非只取最高分 | 保留原始分数、阈值和候选版本 |
| 2. 季节与自然背景 | 同季历史、稳定邻域、降雨、土壤湿度、水位、潮位、阴影几何 | 分出正常周期、自然扰动和无法解释的变化 | 自然原因只能在有支持证据时确认；不凭一个指数硬排除 |
| 3. 对象类型 | 面积、宽度、形状、纹理、扩张方向、地形、道路/堆场/采坑组合；难负例分类 | 分成疑似采挖、施工、农业、自然变化和未知 | 不以“原来是耕地”“远离已知矿点”为硬排除条件 |
| 4. 时序持续性 | 至少两次有效独立日期的直接变化证据，或一次强证据加独立来源核实 | 提升持续、扩大的对象；孤立弱信号待观察 | 不能把同次观测的多个指数、相邻像元或累积量连续超阈值当成独立证据 |
| 5. 跨源与高分核查 | 不同传感器、明确日期的高分前后影像、必要的无人机与现场照片 | 确认地表变化及可能的活动类型 | 光学和SAR冲突时先查时间、尺度和湿度，不机械投票；模型派生结果不作独立真值 |
| 6. 时空许可核验 | 事发区间内有效的矿权、采砂许可、审批、禁限采范围与时段 | 分为许可冲突待核、许可可能覆盖、资料不足 | 边界附近设置位置不确定带；矿权内不自动合法，矿权外也不自动违法 |
| 7. 人工与现场闭环 | 双人影像研判、材料核查、现场确认、结果回填 | 形成待核、排除、持续关注、已核实等状态 | 结论注明责任人、日期和依据；现场未完成时不得写成已确认违法 |

持续性规则不能阻碍紧急核查。对于一次高质量高分影像已显示明显新增大规模采挖、且涉及敏感区的线索，可直接进入人工高优先级队列；不必为了凑足两次卫星观测而延误处置。

### 3. 每层都记录漏损，不能只展示“筛得越来越少”

每个对象保存`保留/分流/排除/未知`及原因码，记录输入影像、有效日期、模型版本、阈值、人工更改和下游状态。每层统计进入数、保留数、未知数、排除数，以及抽查发现的漏报。

多层硬过滤容易叠加漏检：若每层独立保留95%的真目标，连续5层仅保留约77.4%。现实层间并不独立，这个数字只是说明风险；最终必须直接评价完整链条的召回率，而不是拿单层精度相乘后当作实际性能。

建议优先用软评分、解释字段和人工复核缩小范围；只有明确的观测伪影适合自动硬排除。每月对低分、被排除和无候选区域做分层抽样；保留小面积、边界附近、低覆盖和新地类样本，防止优化只惠及容易识别的大矿坑。

### 4. 用独立参考资料证明有效，而不是用模型验证模型

**样本设计：** 同时抽取高分候选、低分候选、各层被排除对象、普通非候选区域和高风险非候选区域。按区域、地类、季节、面积档、可见性和传感器分层；不等比例抽样时记录纳入概率，评价使用相应权重。[外部8]

**参考判读：** 使用日期明确、足够接近目标时段的高分辨率前后影像和现场记录；至少两名判读者独立判读，分歧经仲裁。标签至少分“目标活动、非目标活动、未知”。“违法”另设业务结论字段，必须有许可及核查依据。2026年现状影像不能单独证明2025年某次变化的性质或日期。

**数据划分：** 同一矿点、同一事件及其相邻切片不得跨训练和测试集。采用空间块或矿点留出，并设置未来时段测试；不能随机拆相邻像元宣称泛化能力。现有68个候选中，凡参与调参或规则设计的对象只能作为开发或诊断材料，不能再作为独立测试样本。

**历史回放：** 每个测试时刻只使用当时已可获得的数据。不能把全年最大值、未来晴空图、后来形成的地类图或未来人工反馈送入当期模型。记录实际数据交付时间，分别评估“影像已经到达后的算法延迟”和“事件发生后的发现延迟”。

**对照试验：** 保留简单双时相/指数基线，依次加入季节模型、对象分类、SAR和高分核查；在相同独立样本上比较误报、漏报、时延与成本。只有带来稳定增益的模块才接入生产。

### 5. 验收指标与可操作的检验要求

核心指标使用事件级Precision、Recall、F1；事先约定对象匹配的空间及时间容差，防止一个事件被拆成多个“命中”。面积、边界和像元精度单独报告，不替代事件发现能力。

`Precision = TP / (TP + FP)`

`Recall = TP / (TP + FN)`

`F1 = 2 × Precision × Recall / (Precision + Recall)`

其中TP/FP/FN应相对于明确的活动类别与观察时段定义。未知不计入TN，也不能悄悄删除后只报已判明样本的漂亮结果；需同时报告未知率、原因、覆盖率，必要时做未知样本极端归类下的敏感性分析。全链条覆盖不足造成的遗漏不能被条件精度掩盖。

还应同步报告：

- 每1000平方公里、每月的误报事件数；同时注明有效可观测面积与面积时长。
- 每次人工核查耗时、每个已确认有效线索的成本、积压和超时率。
- 有效观测间隔的中位数与P90、对象晴空覆盖率、最长无观测时长。
- 新影像到达至候选生成、候选至初核的P50/P90时延。
- 不同地区、季节、资源类型、面积和最窄宽度档的召回率。
- 置信度校准、未知/拒判比例、事件重复率以及被排除样本的抽查漏报率。

简单独立比例可使用Wilson区间；空间相关样本应按矿点或空间块分组bootstrap。不等概率抽样需要相应加权。样本规模由区间精度和事件稀缺性决定：例如按预期Precision约0.80、95%区间半宽约0.05作简单近似，需约246个已判明的预测正事件；相关性、未知和分层会提高需求。这是规划量级，不是当前样本已满足要求，也不能通过复制图斑凑数。

建议先在历史独立样本上冻结模型和阈值，再进行连续影子运行，覆盖不同天气与业务场景。只有“误报量不超过核查承载力、关键目标召回达到约定值、覆盖和时延明确、故障可恢复”同时通过，才对外称为运行中的预警系统。具体阈值应由试运行结果和主管部门共同确定，不在缺少真值时虚设达标数字。

## 五、还需要什么数据、资源与建设条件

### 1. 数据按阻塞程度分级补齐

| 优先级 | 所需数据 | 关键内容与获取方向 | 缺失时的边界 |
|---|---|---|---|
| P0 | 正式监测边界与基础地理 | 烟台行政边界、乡镇、河道/岸线、统一坐标系及精度；向有权部门获取 | 无法准确声明全市覆盖和辖区归属 |
| P0 | 许可与管理约束 | 采矿权、有效期、许可矿种及范围、采砂许可与禁采期、河道管理范围、工程及修复审批、生态保护和耕地林地约束；保留历史版本 | 只能输出扰动或疑似活动，不能可靠输出无证、越界等业务判断 |
| P0 | 同期独立参考资料 | 2025年分季节、日期明确的高分影像；已核实历史活动、合法工程和现场反馈 | 无法证明当前模型精度，也无法用后一年影像补出前一年真值 |
| P0 | 可持续获取的多源影像 | 多年Sentinel-2/Landsat、必要的HLS与Sentinel-1；保存产品ID、获取时间、处理基线和质量字段 | 回顾性试验无法转成滚动预警 |
| P1 | 高分辨率历史与新增影像 | 优先协调省市已有正射影像、高分数据；不足部分采购合规商业数据或依法航测；需明确日期、分辨率、云量、侧视角和交付时限 | 小目标识别、难例复核和精确边界判断受限 |
| P1 | 气象、水文和潮汐 | 降雨、积雪、必要的土壤湿度；重点河段水位流量、洪水过程；海岸潮位 | 农业、湿度、河滩及岸线误报难以充分解释 |
| P1 | DEM及必要的高精度地形 | 开放DEM用于坡度、阴影与雷达地形处理；重点区需要测量基准一致的高精度DEM/DSM | 开放30米DEM不能支撑可靠的小采坑体积估算 |
| P1 | 本地标注与现场闭环库 | 目标、难负例、未知样本；时间、几何、判读者、理由和核查材料；持续补充漏报 | 模型难以从“像变化”走向“像目标活动” |
| P2 | 重点区地面观测 | 经授权的视频、无人机巡查、必要的GNSS或地面形变监测；设备和访问权限可审计 | 无法承诺固定点位分钟级告警或验证地下活动 |

P0是可信分析与业务判断的基础；P1决定精度和可用性；P2按目标风险与时效选择，并非全市必须铺设。OSM、WorldCover、Dynamic World可作背景与初筛辅助，不能代替法定权属、最新地类核实或独立活动标签。网络底图若无明确采集日期与分析授权，只能用于定位展示。

对高分影像不要只采购“分辨率”：合同还应约定最小采购面积、实际覆盖、云及薄云标准、侧视角、定位精度、失败补拍、原始多光谱交付、分析授权和交付时限。全色锐化产品的视觉清晰度不等于多光谱信息拥有同样分辨率。

### 2. 权属核验需要时间与位置不确定性

许可数据至少包含编号、主体、几何边界、坐标系、有效起止日期、许可事项、变更/注销状态和来源。采砂另需适用河段、时段及批准条件；矿权涉及深度或其他限制时，二维影像不能代替相应核查。

应在事件可能发生区间内匹配许可历史，而不是拿今天的许可判断几年前的活动。若影像变化区间跨越许可生效或失效日，输出“时间上无法判定”，再补充材料。

影像、提取边界和权属测绘都有位置误差。利用实测配准误差和权属精度设置边界不确定带，分别统计明确内侧、边界待核和明确外侧的面积。不能把几米的视觉错位直接认定为越界，也不能因质心落在许可内就认为整个图斑受许可覆盖。

面积、距离和缓冲分析使用适合当地的米制投影，优先衔接正式资料采用的CGCS2000投影及其参数。经纬度和Web Mercator只作交换或展示用途，不直接用于精确面积、距离判断；互联网底图与正式数据若采用不同坐标表达，须明确转换流程，不能根据屏幕偏移修改权属边界。

### 3. 工程与算力资源

现有FastAPI及地图、图表界面可继续使用。工程重点应放在数据和事件链，不必先重做展示页面：

1. **数据入口：** 对公开目录和授权供应商定时检索；按产品ID、采集时间与处理版本去重；新旧重处理产品可追溯。
2. **处理调度：** 建立队列、增量处理、重试和失败隔离；保留原始数据，固定分析网格，缓存按数据及算法版本区分。
3. **存储与空间数据库：** COG保存栅格，PostGIS等管理对象、许可、事件和空间查询；保留原始观测、派生成果和运行清单。
4. **预警状态：** 区分新增、扩大、持续、恢复与资料不足；人工排除后保留复核记录；再次变化可按规则重新打开事件。
5. **质量和服务监控：** 显示最新有效观测时间、数据积压、处理失败与低覆盖区域；数据源中断必须发服务告警，不得显示“无异常”。
6. **可复现与安全：** 固定软件环境、模型与参数版本；记录输入来源和校验值；做好角色权限、审计、备份及敏感数据分级。

初期季节模型、指数和树模型以CPU、内存、磁盘吞吐与网络为主。高分深度学习或大规模InSAR才需要有针对性的GPU和更多存储。可先以一台16—32核、64—128GB内存、NVMe缓存的节点做试点压测；需要训练分割模型时，再评估16—24GB显存或更高配置。以上是测试起点，不是对全市处理时限的容量保证，也不表示当前已有这些设备。

容量应由实际范围和影像方案计算：

`未压缩栅格量 ≈ 面积(m²) / 像元边长² × 波段数 × 每值字节数 × 时相数`

再加质量掩膜、中间文件、金字塔、重处理版本和备份。以10米网格、10个Float32波段、100个时相估算，每平方公里原始数组约40MB；这只是量级示例，不包含SAR SLC、高分影像和上述附加存储。下载压缩率不能直接当作运算内存压缩率。

### 4. 人员与经费必须围绕核查负担配置

最小试点团队需覆盖四类职责：遥感与GIS处理、模型与数据工程、业务许可核验、影像/现场复核。可由少量人员兼任，但开发与独立验收不能完全由同一人完成；高风险线索至少有第二人复核。

复核能力应反推可承受的告警数量：

`日复核人时 = 日候选数 × 单对象平均初核分钟 / 60 + 复杂复核及协调人时`

例如每天100个候选、每个初核8分钟，仅初核约13.3人时；还未计现场核查。应先用实测候选率与用时确定人力，再决定阈值和高分采购策略，不能把减少人工的压力转化为静默删除低分线索。

预算至少包含影像档案与新增采购、任务化观测、标注与专家复核、现场核查、计算存储网络、软件维护和持续更新。采购金额需依据实际面积、频率、交付要求和供应商报价；开放卫星数据免费不等于整个系统零成本。评价新增数据或模型时，应比较“每增加一个有效发现需要多少成本”与“每增加一批影像节省多少漏报/复核时间”。

### 5. 建议按四个验收门槛补齐，而不是一次性堆模型

| 门槛 | 应完成的工作 | 可交付的真实能力 |
|---|---|---|
| G1：结果可信 | 完成v2端到端修订、全年重跑、时空范围核对和质量复核；隔离旧结果 | 可复查的历史样区扰动分析，尚非实时预警 |
| G2：识别有效 | 补齐独立标签和难负例；完成空间/时间留出及分层评价；确定主模型 | 对约定目标、面积和观测条件有可量化的识别能力 |
| G3：持续可用 | 接通新影像、增量处理、事件去重、质量告警和核查队列；通过影子运行 | 新数据到达后自动产生可追溯的新增线索 |
| G4：业务闭环 | 接入历史许可和约束边界；落实人工、现场反馈和服务时限；持续抽查漏报 | 能支撑疑似违规活动预警和核查处置，但违法认定仍须依法完成 |

**最优先投入顺序：先修正并验证现有分析，再补独立真值与正式许可，同时建设持续数据入口；随后根据误报类型增加对象分类、高分直检或SAR。** 对小目标和快速发生的活动，高分/地面观测通常比继续复杂化20米模型更直接；对季节和施工误报，可靠标签、时序背景与审批资料通常比更大的神经网络更关键。
