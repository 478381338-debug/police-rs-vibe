# 章丘专区（济南市章丘区）

入口：主站地图右上提供 `2D / 3D / 研究区 / 中国地图` 四个按钮；2D 与 3D 都同时显示内蒙古大青山和章丘，无区域切换按钮；直接访问 `/zhangqiu` 自动跳回主站。

这是一个**公开数据风险筛查原型**，用于展示真实行政边界、自然地理、公开人文设施和 2D/3D 地形。它不是章丘本地警情系统，也没有接入任何内部警力、案件或重点人员数据。

## 1. 边界与范围

- 行政代码：`370114`（山东省济南市章丘区）。
- 边界来源：DataV 济南市 `370100_full.json` 中的章丘区 Feature，提取为 `data/zhangqiu/boundary.geojson`。
- 边界顶点约 461 个；范围约 `117.1827–117.7473°E`、`36.4339–37.0763°N`。
- 区中心采用边界属性中的 `center`：`[117.54069, 36.71209]`。

## 3. 关注指数（不是警情、不是官方预警）

每个格网计算：

```text
洪涝 = 0.55 * min(1, 3h雨量/50) + 0.25 * 平坦度 + 0.20 * 河流邻近度
林火 = 0.35 * (1-湿度/100) + 0.25 * min(1, 风速/30)
     + 0.20 * (1-土壤湿度/0.4) + 0.20 * min(1, 气温/35)
干旱 = 0.45 * (1-土壤湿度/0.4) + 0.30 * min(1, 气温/35)
     + 0.25 * (1-湿度/100)
地灾 = 0.45 * min(1, 坡度/25) + 0.30 * min(1, 7d雨量/100)
     + 0.25 * 河流邻近度

自然致灾 = max(洪涝, 林火, 干旱, 地灾)
关注指数 = 100 * (0.55*自然致灾 + 0.25*人口暴露
                + 0.10*警务设施可达性 + 0.10*道路可达性)
```

等级：高 ≥70、较高 55–70、中 40–55、低 <40。`dominant` 是模型归因，不是已发生灾情。

## 4. 2D/3D

- 2D：Leaflet + OpenTopoMap/OSM，真实章丘边界、关注格网、公安/医疗/学校/消防 POI、道路、水系、建筑样点。
- 3D：MapLibre GL JS + `/api/terrain/{z}/{x}/{y}.png`（AWS Terrarium）和 `/api/terrain-color`；风险格网以 fill-extrusion 显示，边界金色、公安设施圆点。
- 3D 视图可拖拽旋转、缩放；页面的 `2D 地图 / 3D 地形` 按钮切换。
- 土地覆盖只作为右栏视觉预览：原始 IO LULC tile 分辨率较低，不能当作地块级判读依据。

## 6. 限制

1. 没有章丘本地警情、案件、警力部署数据；不能把“重点巡查格网”说成真实高发案地点。
2. OSM 公开设施可能有遗漏/过期；以属地实际警力台账为准。
3. WorldPop 是 2020 年 1 km 栅格估算，不是第七次人口普查的政区统计；页面显示“人口暴露”并保留来源。
4. 气象是 Open-Meteo 全球预报，不是济南市气象局官方预警。
5. 关注指数是可解释的筛查模型，未用章丘本地灾情/警情做概率校准。
6. 公网页面没有身份认证，只能放公开数据和演示数据；真实内部数据必须部署在授权内网并加认证。
