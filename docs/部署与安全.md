# 部署与安全说明

本文只覆盖本项目的单机部署基线。真正进入公安内网前，还需要按本单位等保、密码应用、数据分类分级和审计要求做专项测评。

## 1. 运行方式

### 本机

```powershell
cd <repo>
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

### Docker

```powershell
copy .env.example .env
# 编辑 .env：至少关闭演示模式、设置公网地址、生成独立证据密钥
docker compose up -d --build
```

Compose 默认只把 8080 绑到 `127.0.0.1`，公网入口应放在 Nginx、政务云网关或 Tailscale Funnel 之后。

## 2. 关键环境变量

| 变量 | 默认 | 生产建议 |
|---|---|---|
| `POLICE_DEMO_MODE` | `1` | 必须 `0`，并修改/禁用演示账号 |
| `POLICE_WEB_USER` | 空 | 演示站访问账号；与下一项都设置才启用口令页 |
| `POLICE_WEB_PASSWORD` | 空 | 强口令；生产应通过环境/密钥管理注入 |
| `POLICE_GATE_HOURS` | `12` | 访问口令 Cookie 有效期（小时） |
| `POLICE_GATE_MAX_FAILS` | `5` | 同一地址+账号在锁定窗口内允许的失败次数 |
| `POLICE_GATE_LOCK_MINUTES` | `15` | 达到失败次数后的锁定时长（分钟，最小 1 分钟） |
| `POLICE_PUBLIC_BASE_URL` | 空 | 设为实际 HTTPS 入口，用于到场码链接和二维码 |
| `POLICE_COOKIE_SECURE` | `0` | HTTPS 下设为 `1` |
| `POLICE_TRUST_PROXY` | `0` | 仅在请求确实经过可信反代时设为 `1` |
| `POLICE_HSTS` | `0` | 全站强制 HTTPS 后再设 `1` |
| `POLICE_DISABLE_DOCS` | `0` | 生产设为 `1`，关闭 `/docs`、`/redoc`、`/openapi.json` |
| `POLICE_CORS_ORIGINS` | 空 | 同源部署留空；跨域时逐条列明 |
| `POLICE_EVIDENCE_KEY` | 空 | 用密钥管理系统注入；留空则生成 `instance/.evidence_key` |
| `POLICE_INSTANCE_DIR` | 项目内 `instance` | Docker 中为 `/app/instance` |
| `POLICE_MAX_EVIDENCE_MB` | `50` | 按现场网络和存储调整 |

## 3. 安全基线

### 已实现

- 同源 CORS 白名单，不再使用 `*`；只允许 `GET/POST/PATCH/OPTIONS`。
- 会话 Cookie 为 HttpOnly、SameSite=Lax；HTTPS 下可加 Secure。
- 证据 SHA-256、HMAC 链头、案件级链头锚定；深度校验会重算文件字节。
- 到场码只存 SHA-256 哈希，支持有效期、次数上限、作废；令牌放在 URL 片段，不进入服务端访问日志。
- 安全响应头：`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`、`Cross-Origin-Opener-Policy`、CSP。
- 进程内限流：
  - 登录 `POLICE_RATE_LOGIN_PER_MIN`，默认 10 次/分钟/IP；
  - 访问口令失败按“地址+账号”计数，默认 5 次后锁定 15 分钟，返回 429 与 `Retry-After`；
  - 到达圈、无人机规划 `POLICE_RATE_EXPENSIVE_PER_MIN`，默认 30 次/分钟/IP；
  - 刷新任务默认 6 次/5 分钟/IP；
  - 其他 API 默认 300 次/分钟/IP。
- `/api/health` 返回版本、运行时长、数据库/证据目录/证据密钥状态；`/api/health/ready` 在降级时返回 503。
- Docker 以非 root 用户运行，`cap_drop: ALL`，`no-new-privileges`，实例/日志/缓存以卷持久化。

### 仍需在部署层完成

- TLS 终止、证书管理、强制 HTTPS、HSTS 预加载。
- 反向代理层的总限流、连接数限制、请求体上限、慢速攻击防护。
- 账号体系接入统一身份认证/LDAP/OIDC；本项目内置账号只适合演示和小规模试用。
- 数据库备份、证据文件备份、密钥分离保管、恢复演练。
- 日志集中收集、保留期限、审计只读账号；不要把证据原文写入普通日志。
- 主机加固、漏洞扫描、依赖升级、等保测评和密码应用评估。

## 4. 反向代理要点

- 只反代 `127.0.0.1:8080`，不要直接暴露 Uvicorn。
- 传入 `X-Forwarded-Proto`、`X-Forwarded-For`；同时把应用侧 `POLICE_TRUST_PROXY=1`。
- 请求体上限至少覆盖 `POLICE_MAX_EVIDENCE_MB`，并留出 multipart 开销。
- 静态资源可缓存；`/api/auth/*`、`/workspace`、`/api/cases/*` 不要被公共 CDN 缓存。
- Tailscale Funnel 场景下，公网域名写入 `POLICE_PUBLIC_BASE_URL`，否则到场码会指向内网地址。

## 5. 数据与许可

- 遥感/气象：MPC STAC、Landsat、Sentinel-2、MODIS、Open-Meteo、AWS Terrarium DEM。
- OpenStreetMap 数据遵循 ODbL，公开分发衍生数据时需保留署名并注意 share-alike。
- WorldPop 遵循 CC BY 4.0，需保留署名。
- 本项目不包含真实警务数据；演示案件、证据、账号均在本机 SQLite 中。

## 7. 已知边界

- 限流是单进程内存计数，多副本部署时每个副本独立计数；应在网关统一限流或改用 Redis。
- CSP 为兼容现有内联样式和脚本保留了 `unsafe-inline`/`unsafe-eval`，不是强 XSS 防护；后续应逐步移除内联脚本并收紧。
- 证据链只能证明“登记后文件未改动”，不能证明拍摄时间、地点和拍摄者身份；不是法定电子签章。
- OSRM 公共实例无 SLA；生产应自建或签约，并保留直线降级逻辑。
- 无人机航线未接入禁飞区、空域审批、风场、电池和避障模型，不能直接作为飞行依据。
