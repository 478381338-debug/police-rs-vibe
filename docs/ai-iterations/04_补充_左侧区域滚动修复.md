## 4. AI 最终交付说明（原文节选）

```text
左侧面板现在可以滚动了：我用 Playwright 实测在 1037/1600 宽度下都能滚到底，并看到了完整的「观测覆盖 / 观测与资料缺口」；700px 移动端布局也不受影响（整页滚动，`min-height` 撑开，无内容被裁）。

**原因**：`.yw-queue` 是固定高度（`calc(100vh - 58px)`）的 flex 列，且 `overflow: hidden`；里面「观测覆盖」块写了 `flex: 0 0 auto` 不会收缩，它的文案又很长，于是它溢出到栏外被直接裁掉，同时把事件列表挤成 0 高——整栏既没有滚动条也滚不动。

**改动**（两行 CSS，符合最小改动）：
- [web\yantai-workspace.css:77](web\yantai-workspace.css:77)：`.yw-queue` 由 `overflow: hidden` 改为 `overflow-y: auto; overflow-x: hidden`，让整栏成为滚动容器。
- [web\yantai-workspace.css:97](web\yantai-workspace.css:97)：`.yw-event-list` 去掉内层 `flex: 1` 和 `overflow: auto`，改为 `flex: 0 0 auto` 按内容自然高度展开，避免"外层滚动 + 内层滚动"两层滚动条打架、事件列表又被压成 0 高。
- [web\yantai.html:8](web\yantai.html:8)：CSS 引用版本号 `v=20261115u` → `v=20261116a`，防止浏览器用缓存里的旧样式（这是本次唯一需要强刷的地方）。

滚动方式变为整栏一个滚动条：滚过事件卡片后自然接「观测覆盖」，没有嵌套滚动。CSS 是静态文件，正在运行的 8080 服务不用重启，刷新页面即可看到。
```
