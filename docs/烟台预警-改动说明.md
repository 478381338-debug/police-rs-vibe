# 烟台非法采矿与河道采砂预警专题 · 首轮浮窗改动说明

> 2026-11-15 后续已按增强方案升级为 `/yantai` 独立工作区；本文保留为首轮浮窗实现记录，入口与交互以 `docs/实施记录.md` 第 12 节为准。

- 日期：2026-11-15
- 范围：在现有“遥感一张图”上新增烟台试点专题，不改动案件工作台、移动核查、多场景研判等既有业务；仅对 `index.html`、`main.py` 做接线。
- 依据：`docs/烟台非法采矿与河道采砂真实预警实施方案.md`

## 1. 改动概览

在遥感地图工具栏“中国地图”右侧新增橙色 **“烟台预警”** 入口。页面首次打开时，右侧自动展开烟台专题浮窗；关闭后可用该按钮或 `/?yantai=1` 重新打开。

浮窗包含：

- 烟台试点小地图，标注 22 个资源点、3 条河段和事件位置；
- **事件**：3 条试点线索，按 P1/P2/P3/Q 分级；
- **矿区**：21 个 OSM 采石场 + 1 个 P07 遥感采石场；
- **河段**：界河、王河、大沽夹河 OSM 中心线；
- 事件详情：活动判断、合规判断、优先级、面积、时相、中心坐标、触发规则、限制、证据影像；
- 研判记录：需补许可 / 需高分复核 / 需现场核查 / 非采掘变化；
- 检查更新：只检查本地试点数据，并明确提示“非实时卫星推送”。

## 2. 页面效果

- 工具栏：`2D | 3D | 研究区 | 中国地图 | 烟台预警`
- 浮窗位置：右侧固定，1366×768 下约 438×645 px，不产生横向滚动；
- 首次打开自动展开，避免用户找不到入口；
- 小地图独立使用 OSM 瓦片，不与主图 Esri 代理混用；
- 页面明确展示“试点 / 资料待核 / 非实时卫星推送”，不显示“违法概率”。

## 5. API

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/yantai` | 307 到 `/?yantai=1`，打开主图并自动展开浮窗 |
| GET | `/api/yantai/overview` | 试点概览、计数、覆盖、数据状态 |
| GET | `/api/yantai/resources` | 资源点 |
| GET | `/api/yantai/rivers` | 河段 |
| GET | `/api/yantai/events` | 事件列表，可按 priority/domain/status 过滤 |
| GET | `/api/yantai/events/{id}` | 事件详情与证据 |
| POST | `/api/yantai/events/{id}/review` | 写入研判记录 |
| POST | `/api/yantai/check` | 检查本地试点数据，返回检查时间与覆盖 |
| GET | `/api/yantai/asset/{name}` | P07 影像资产 |

研判记录写入 `instance/yantai_reviews.json`，不写案件库，不影响正式案件。

## 7. 已知边界

- OSM 采石场、河段只是公开背景，不是正式矿权、许可范围或违法认定；
- 未取得许可、水文和现场材料时，页面统一写“许可待核/无法判断”，不生成“违法概率”；
- 当前只有招远 P07 一个 5.3×5.6 km 的 10 m 试点，不是全市实时监测；
- 10 m 影像不能确认地下开采或 1 m 级目标，不能替代现场核查；
- 主图既有 Esri 底图上游仍有 502，烟台小地图使用 OSM，不受影响。

## 8. 使用方式

1. 登录遥感地图；
2. 页面右侧自动出现“烟台预警”，或点击顶部橙色按钮；
3. 在“事件”中点击卡片查看详情；
4. 选择研判结论写入本地记录；
5. 需要资源背景时切换“矿区/河段”；
6. 需要重新打开时访问 `http://127.0.0.1:8080/yantai`。
